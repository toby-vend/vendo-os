(the "Watch (Dropbox)" column). Downloaded 2026-09-16.

Filenames are `<sheet ref>-<treatment>-<creative name>.mp4`, so any file traces
straight back to its row of ad copy in the sheet, and to the matching transcript
in `../transcripts/`.

Not committed to git — these are large binaries, re-downloadable from the sheet.
`manifest.json` (if present) holds the original Dropbox links.
