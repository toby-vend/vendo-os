Light rounded-stroke line icons matching Vendo's brand iconography (Lucide-derived). `stroke = currentColor`.

```jsx
<Icon name="trending-up" size={20} color="var(--accent)" />
<Icon name="arrow-up-right" size={16} />
```

- `name`: one of `iconNames` (phone, mail, map-pin, cursor, search, arrow-right, arrow-up-right, trending-up, target, megaphone, users, …).
- Default colour follows text; pass `color="var(--accent)"` for brand emphasis.
- Sizes: 16 (dense UI) · 20 (default) · 24 (touch / marketing). Never use emoji as icons.
