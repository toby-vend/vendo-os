Why period, not product type

The instinct is to release all the skirtings, then all the architraves. The product data argues against it. The first key benefit on every page reads "pair with the matching skirting, panel mould and architrave", and the whole proposition of a 20 × 4 matrix is that a room can be specified in one profile. Release by type and every page cross-sells to three products that do not exist yet. Release by period and each drop is a complete, specifiable room set with its own editorial story, photography and audience.

Blocking · fix before publishing

The range is named after a term nobody searches

All 79 titles, URL handles and SEO titles contain "Tulip". None contain "hardwood" or "solid wood". Keep the profile names — The Aysgarth, The Helmsley are a genuine premium brand asset that works like a paint or tile range. Make the layer above them findable: the collection is Solid Hardwood Skirting Boards, and each title carries the searchable noun with tulipwood as the named timber. Handles matter most and are cheapest to change now — renaming after launch means redirects and lost equity.

Blocking

The priming and size options are inconsistent

59 products: "Priming" → "Un-Primed"
20 products: "Primed"  → "Not Primed"

Two option names and two words for the same thing. This fragments the storefront filter and splits the range across duplicate facets. Size has the same problem — Thickness x Height on 59 against Thickness x Width on 20.

Check

The from_price metafield is empty on all 79. Native pricing should cover it, but collection cards read that metafield — check against a real product or they render with no price.

Copy

Every page compares tulip wood to softwood. This buyer is coming from an MDF catalogue and deciding between MDF and hardwood at twice the price. Answer that question instead.
